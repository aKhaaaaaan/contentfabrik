Contentfabrik

A private production tool for short educational videos.

What it does

Contentfabrik creates short, fact-checked explainer videos (YouTube Shorts) for the operator's own channels, for example about new open-source AI models or the history of well-known companies. Every script is written from public sources (such as Wikipedia, GitHub and Hugging Face), checked against those sources, and reviewed by the operator before it is published.

How it uses YouTube

  • Uploading finished videos to the operator's own YouTube channels.
  • Reading view counts, watch time and similar statistics of those channels to learn which videos work best.

The tool is used only by its operator for their own channels. It does not access other people's accounts, and it does not sell or share any data.
