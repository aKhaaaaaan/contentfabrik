2. What Contentfabrik is

Contentfabrik is a private tool that produces short educational videos and uploads them to the operator's own YouTube channels. It is used only by its operator. It is not offered to the public and has no user accounts.

3. Which data the tool accesses

Through the YouTube API Services, and only for the operator's own channels, the tool:

  • uploads videos together with title, description and settings;
  • reads channel and video information (titles, IDs, publication status);
  • reads aggregated statistics such as views, likes, comments, shares, watch time and audience retention (YouTube Analytics).

The tool does not access personal data of viewers. YouTube statistics are aggregated by YouTube and do not identify individual people.

4. Why the data is used

Solely to publish the operator's videos and to learn which videos perform well, so that future videos can be improved. The data is not sold, not shared with third parties, not used for advertising and not used to build profiles of anyone.

5. Where the data is stored and for how long

Access tokens are stored as encrypted secrets in the operator's private code repository (GitHub) and on the operator's own computer. Video statistics are stored in that private repository and kept as long as they are useful for improving videos, at most for the lifetime of the channels. They can be deleted at any time by deleting the repository files.

6. Google and YouTube

Contentfabrik uses YouTube API Services. By using it, the operator is bound by the YouTube Terms of Service. Data handled by Google is subject to the Google Privacy Policy.

Contentfabrik's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time in the Google account security settings: myaccount.google.com/permissions.

7. Other services the tool uses

  • Google Gemini API (writing and checking scripts, reviewing finished videos). Only public source texts and the finished videos are sent; no personal data.
  • Pixabay (free stock video clips), Wikipedia / Wikimedia Commons (facts and freely licensed photos), GitHub and Hugging Face (public information about AI tools).
  • Telegram (delivering finished videos to the operator for approval).
